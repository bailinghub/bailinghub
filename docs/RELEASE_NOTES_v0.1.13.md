# BailingHub v0.1.13：语音转写与分发版本一致性

`v0.1.13` 是承接 `v0.1.12` 语音转写修复的分发闭环版本。运行时语义不变；本版本把安装脚本、默认镜像、验证任务卡和公开版本元数据统一到同一个发布号，避免不同入口拉取不同版本。

## 用户可见结果

- 网页聊天语音输入继续使用显式 `transcribe`、`inline` 或 `off` 策略。
- `transcribe` 继续由独立语音模型先把音频转换为文本，主模型只接收文本。
- 专用语音配置缺失、禁用或无法解析时继续失败关闭，不回退到主模型猜测或直传音频。
- 一键安装、源码镜像 Compose 与独立验证任务卡现在统一使用 `v0.1.13`。

## 分发一致性修正

本版本统一了：

- `package.json` 与锁文件版本；
- 一键安装脚本的镜像标签兜底值；
- 镜像 Compose 的默认应用镜像标签；
- 镜像构建与标签检查脚本的兜底值；
- 中英文独立验证基线；
- 独立验证 Issue 模板；
- 中英文发布记录和文档索引。

正式发布前必须确认 GitHub Release、源码包、安装脚本和两个官方应用镜像都对应同一提交和版本。

## 兼容性

- 无数据库迁移。
- 不修改 Client API、执行器协议、工具签名、审批语义或 ACC。
- 不修改 `v0.1.12` 已发布的语音策略。
- `v0.1.12` 部署无需迁移配置；升级只需使用 `v0.1.13` 镜像或源码。

## 验证

```bash
npm run release:check
```

发布闭环还需执行正式分发校验和官方镜像标签检查，确认默认安装路径可以获取 `v0.1.13`。
