# Current release: Core 0.10.0

Core 0.10.0 adds Agent-only on-demand knowledge, full tool guidance and explicit model-output policies, with onboarding, draft, approval and diagnostic interaction fixes. No new SQL is added relative to 0.9.4. Existing clients, model configurations and bundled chat retain compatible behavior. MCP / Agent Client SDK 0.8.0 and DSH 0.8.0 upgrade independently; hosts implement their own task continuation.
