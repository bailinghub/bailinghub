# Current release: Core 0.9.4

Core 0.9.4 removes the unused DOCX CLI dependency chain and adds durable notifications for new terminal transitions and approval prompts, bundled console retry and persistent metrics. Explicitly apply 068; receivers deduplicate event IDs, unknown receipt requires operator verification, and business parents are not rerun. SDK 0.7.0 / DSH 0.7.0 remain unchanged; independent consumers upgrade separately.
