# BailingHub v0.6.1：看完整沟通，再追到每次业务操作

一次对话可能先查询 A 账户，再修改 B 账户。以前，管理员需要打开各自的执行记录，看到的往往只是各自做了什么。现在，使用支持的新客户端，可以先阅读完整沟通过程，再追到每份授权的具体操作和审批。

0.6.1与0.6.0的业务功能、接口和数据库迁移相同。0.6.0的npm包内容已验证，但来源提交元数据缺失，未完成正式Release；0.6.1补齐发布来源校验，并作为推荐安装版本。已应用057的部署无需重复建表。

## 你会看到什么变化

- **一处看沟通经过**：控制台“任务→会话”新增客户端完整对话视图，按轮显示已同步的用户输入、中间说明和最终回复。
- **从回复追到操作**：每轮可展开各授权对应的原执行记录，继续查看工具调用、审批和结果；原来的授权记录入口仍保留。
- **多账户也能看清对象**：配套新 SDK 与 DSH 插件后，用户先选择同一业务系统的 A、B 授权，Agent 再为每次操作选用对应权限。账户的业务身份、审批和记忆保持独立。
- **缺记录时如实提示**：业务完成与对话同步分别判断。客户端断网后可以补传已保存事件；确认回包丢失不会重复写入。原文没有保存完整时，界面必须显示缺口，不把执行摘要当成原文。

[先看使用者指南](user-guide/conversations.md)，再按需要阅读[开发者接入契约](AGENT_CONVERSATION_AUDIT.md)。

## 谁需要升级，哪些组件要一起准备

| 你的使用方式 | 此次升级建议 |
|---|---|
| 运行 BailingHub，想在后台追溯完整的本地智能体对话 | 升级 Core 到0.6.1并应用新增迁移；确认客户端已接入可见对话同步。 |
| 使用 DeepSeek Harness 操作多个业务账户 | 使用独立的 `dsh-bailinghub@0.4.0`；其精确依赖 `bailinghub-mcp-server@0.4.0`。按插件说明分别授权，并在首消息前选择本次范围。 |
| 自研桌面或其他智能体客户端 | 使用 Agent Client SDK0.4.0，接入会话范围、真实可见历史、持久归档与状态显示。只更换包版本不足以完成宿主接入。 |
| 只用网页聊天、Client API、Dify/n8n任务或静态MCP | 原入口继续使用，不要求新增本地客户端。其他适配器仍是独立发布项目。 |

先准备 Core，再升级 SDK 和客户端。单独升级 Core 不能让旧客户端自动上传完整原文；单独升级插件也不能让旧 Core 获得归档接口。此次多授权体验限同一业务系统、同一工作区，不宣称跨系统或跨路由编排。

## 已有部署如何升级

1. 按[运维升级指南](OPERATIONS.md)备份数据库，并保留旧代码或镜像。
2. 使用精确的 `v0.6.1` 代码或镜像，由一个部署步骤运行迁移。新增 `sql/057_agent_conversation_audit.sql` 只创建三张归档表；已有迁移不改写，运行时启动也不会自动执行迁移。
3. 启动新版并确认 `/health/ready` 正常，打开控制台“任务→会话”。使用新的客户端对话验证完整文本与原执行记录之间的关联。
4. 按 SDK/插件的迁移说明升级客户端。**新会话未选择授权时只有普通聊天**；首次发送后范围固定，改选需要新会话。重开原会话只恢复原授权。
5. 用测试数据验证断网重开后在同一运行时恢复、撤销原授权仍阻断、取消后不重新启用已结束操作。不要通过重复业务写操作来补齐审计。

回退旧代码时保留新增表和客户端待传事件。旧客户端仍可使用原接口；旧 Core 不支持新归档时，客户端应明确显示不支持，不丢弃原记录。

## 权限与记录边界

完整文本供当前中枢管理审计域中具有任务读取权限的管理员查看。Agent 没有读取聚合正文的接口，混合回复也不会回流到每个账户的模型记忆。每份授权的业务权限与审批仍按原规则执行，业务系统继续做最终校验。

归档只覆盖客户端实际可见的文本和原执行关联，不包含隐藏推理、附件或任意本地工具原始输出。无法还原过去没有保存的原文；范围恢复也不表示能跨进程恢复丢失的业务任务。业务后端的能力声明、业务 SDK 和审批规则无需为本次归档功能调整。

ACC规范、各生态适配器、独立客户端与托管环境保持各自边界；它们不被合并为Core的一部分，也不因Core发布而自动升级。

## 检查与进一步阅读

发布提交须通过 `npm run release:check`，覆盖权限与成员校验、事件幂等、执行关联、控制台、现有Client API/SDK兼容性、安全与制品边界。配套客户端另有离线恢复、保存失败和取消竞态回归。验证使用公开测试或隔离合成数据，不表示生产采用。
