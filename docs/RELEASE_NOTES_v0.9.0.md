# 百灵中枢 v0.9.0：模型服务与统一套餐额度

版本：**Core 0.9.0 / MCP 与 Agent Client SDK 0.7.0 / DSH 0.7.0**。本页说明相对公开 Core 0.8.0 的变化与升级影响。

企业业务助手需要在对话中选择模型、生成活动图片，再调用已获授权的业务接口。管理员现在可以为这些模型与生成工具配置一份共享额度；本地宿主继续负责对话和任务编排，中枢记录原请求、计量及结算，原业务权限与审批继续生效。

## 可选的微型模型计费网关

模型计费按需启用。管理员配置模型连接、实际调用型号、参考计价模型与端点，再创建套餐并开通给个人或组织共享账户。对话模型与模型工具进入独立目录，宿主按能力发现接入；中枢不按用户轮次或任务步数收费。

实际调用型号可以与参考目录中的型号不同，管理员需要显式核对映射。参考价格来自 OpenRouter，**不代表实际模型供应商的实付价格或账单**。每个请求保留参考价格和套餐倍率快照，后续调价不重算历史请求。配置未就绪的服务不会进入可调用目录，宿主可读取原因并提示联系管理员。

## 一个套餐、一份 USD 额度

套餐统一使用 USD 计量，同一套餐内所有模型与工具共用额度与一个倍率。例如“企业服务助手”月套餐售价 300 USD，每月额度 100 USD，倍率 1.5；一次请求参考费用 0.20 USD，结算扣除 0.30 USD，实际剩余额度占比为 99.70%。

- **周期套餐**：售价 `priceUsd` 与每周期额度 `periodAllowanceUsd` 分开设置。按日、周或月恢复额度，客户显示剩余百分比；分母是周期额度。
- **额度包**：`priceUsd` 提供一次性 USD 额度，客户显示 Credits（积分），固定 1 USD = 1000 Credits。没有独立积分账本。
- 有效期与重置周期分开，最后不足一个完整周期仍提供完整额度，到期停止新请求，未用额度不结转。模板改价不会重置已开通账户的原额度条款；当前模型集合和统一倍率按套餐读取。
- 支付、汇率、退款及商品定价由业务侧处理。原始 Token 是用量记录，不是套餐上限或百分比分母。

## 文生图与异步结算

模型工具声明名称、用途、参数及输出，宿主负责选择并调用。首批可执行适配为阿里云 OpenAI Images 兼容接口、DashScope 原生接口和 OpenRouter Images 接口的文生图。视频、语音与自定义能力可以保存声明；没有执行适配时明确不可调用，不表示已支持生成。

图片请求保存派发记录后异步完成，宿主用原 `operation_id` 查询结果。结果完成即可使用，计费可能仍在等待实际计量；缺少可信计量不猜测费用或伪造 Token。余额为正时允许新请求，并发晚结算可能产生超额，余额耗尽后阻止新请求。

断网、回包丢失或结果未知时保持原 ID，不另建生成请求。明确拒绝与结果未知分开展示；取消后的晚到结果仍可记录用量，不恢复已结束轮次。图片 URL/Base64 可由宿主按需写入已有附件空间，生成成功不会自动修改业务数据。

## 后台日常管理

- 套餐移除保留原 ID、历史开通、额度池、请求及账本；仍被有效开通使用的套餐需要先处理使用关系。停用模板只停止新开通。
- 个人账户和组织共享账户停用后可移除归档；恢复回原账户的停用状态，旧凭证与被撤销成员不恢复，额度不补发。
- 有权限的管理员可为启用账户手动重置中枢维护的有效套餐：周期套餐恢复到原周期额度并重新起算周期，额度包恢复原始积分。到期时间不延长；原在途请求仍向原额度池结算。
- 控制台的接入示例使用通用业务助手和企业服务描述，便于各类业务系统复用。

## 升级影响与验收

从公开 Core 0.8.0 升级时，通过正式迁移器应用新增的 `063_usage_model_billing.sql` 和 `064_period_plan_allowance.sql`，保留原数据和迁移账本。**正常公开版升级不要求清退真实数据或旧测试数据。** 已部署过计费预览的实例另按[周期额度说明](PERIOD_ALLOWANCE_UPGRADE.md)核对原快照。

客户端宿主按需接入模型目录、工具、摘要与原请求持久记录；业务后端仅在需要开通套餐或提供套餐范围身份时接入对应接口。只使用既有业务工具的部署无需开启模型计费。原身份、权限、会话范围、审批、长任务控制与业务调用归档保持独立。

验收应覆盖所启用的服务配置、额度展示、实际计量、原 ID 查询及管理操作，并核对最终制品与配套版本。自动化通过不等于供应商、客户端或生产环境的实际验收。
