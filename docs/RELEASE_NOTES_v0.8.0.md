# 百灵中枢 v0.8.0：让业务长任务可继续、可控制

发布版本：0.8.0。配套：Core 0.8.0 / Agent Client SDK 0.6.0 / DSH 0.6.0。相对上一公开版本的变化如下。

用户让助手整理一批商城商品，过程中可能先查库存、生成展示图、修改商品，再等待业务审批。对话变长后，开发者需要解决的不只是“能不能调用接口”，还包括工具切换是否顺畅、中断后如何核对，以及管理员如何控制整项任务。

这一轮更新围绕这些步骤完善中枢和配套客户端。多系统授权、授权主体名称和完整可见对话在上一公开版已经提供，本次延续这些能力。

## 更新了什么

### 一个任务，跨轮次累计额度

管理员可在“智能体客户端 → 任务控制”为任务固定授权成员、允许使用的工具、累计写调用上限、在途许可上限和可选截止时间。例如“核对库存并维护商城商品，最多 20 次写调用”。切换工具、发送下一条消息或重开客户端，不会重新获得一份任务额度。

写额度按原业务调用计数，不按商品数或成功次数计数：一个批量接口修改 20 件商品，仍是一笔调用。读操作不消耗写额度，但占用在途许可。已有业务权限和逐笔审批继续生效。

暂停阻止后续派发；已经取得许可的请求可能完成。继续任务不增加额度，也不自动继续任何原操作。取消停止后续派发，不能撤回已发生的业务变化或自动回滚。

### 核对结果不会顺带执行

“商品上架已批准”和“商品已上架”是两件事。新增只读原调用回执，管理端与已适配宿主可以核对执行、审批和派发记录，刷新状态不会提交上架。

用户明确继续时，仍使用原授权、参数、运行记录和调用 ID。写请求已经发出而结果未知时，只核对原记录，不另建一次写操作。配套 DSH 提供会话重开后的持久恢复，以及无活跃对话轮次时的面板核对和继续接口；具体界面由客户端宿主接入。

### 限额可以按部署规模设置

“工具源 → 编辑 → 治理”支持继承业务声明、自定义或关闭中枢单工具限额，并可覆盖指定工具。工具源总闸、单工具限额和接入方限额分别生效。

小时、日限额按原时间窗口计算，不再折算为更小的每分钟额度。相同工具源下同一工具由多个用户与会话共享计数。限流等待提示通过 SDK/DSH 传递；明确未派发的可恢复操作继续使用原调用，不要求模型重新拼写入参数。

### 本地智能体附件空间，首期支持图片

助手可以把生成的活动海报、经营图表，或用户明确指定用于业务的图片，上传到部署方配置的普通 COS、OSS 或显式本地存储，取得 URL 后交给已有业务工具使用。例如把图片设为商城商品主图，或交给内容系统作为活动封面。

首期支持 PNG/JPEG/WebP，单图最高 6 MiB，配套 DSH 每批 1–8 张。上传逐项返回结果，成功地址可以直接复用。普通聊天附件不会自动上传；上传成功和业务修改成功分别判断。图片生成服务、业务图片接口和客户端文件权限仍由各自系统提供。

上传默认关闭，在“智能体客户端 → 配置接入 → 工具与审批 → 生成图片上传”选择存储并启用。首期对象公开读取，文件保留由部署方管理，不随会话结束自动删除。

### 能力发现与错误更容易理解

搜索返回数量、当前加载数量和授权目录数量分别表达；无法确定的总数保持未知。搜索是有上限的相关候选检索，不代表完整遍历。

配套 DSH 在一轮内保留仍有效的工具；已适配宿主还可启用同一存活会话内的跨轮声明复用。例如“创建商品→查询库存→继续编辑商品”不必因一次新搜索就丢掉前面的工具。每轮仍按需准备当前目标，工具声明缓存不替代授权和权限检查。

## 谁需要升级

| 使用者 | 需要做什么 |
| --- | --- |
| 中枢管理员 | 升级 Core、应用未执行的 060–062 迁移；按需配置存储、频率限额和任务控制 |
| 客户端宿主开发者 | 成套升级 SDK/DSH，接入持久记录、正式任务和原调用接口；跨轮复用需要显式启用 |
| 业务后端开发者 | 既有声明、授权、审批和业务 API 可沿用；图片使用仍须业务接口能接收 URL，或提供自己的素材导入能力 |
| 普通插件使用者 | 使用已完成这些接入的宿主；仅升级包不会自动取得本地文件或新增管理权限 |

## 升级和限制

先看[配套升级指南](UPGRADE_v0.8.0.md)。新增迁移分别保存附件回执、限额策略和任务控制记录。使用正式迁移器检查账本，仅执行未应用文件；保留实例配置、密钥、原存储及客户端持久记录。

任务控制按需启用，但纳入任务会为原 Agent Session 设置持续强制标记，影响该授权的其他会话；取消任务也不会解除。先确认全部相关宿主兼容，再用专用测试授权启用。启用后不可回退到不理解该标记的旧 Core。

边界仍是同一 Hub、同一审计域。没有跨系统事务、自动商品对应、整项计划自动续跑、未知写结果自动补偿或业务回滚。附件首期不包含文档、视频或网盘管理。

已完成分组件回归、合成联测和限定客户端接入核对；发行制品需与对应 Tag 及安装摘要一致。Windows 实机及最新面板的实际用户点击尚未覆盖，不据此宣称任意模型或生产场景都已通过。
